# Words used in this guide

Address
:   The number that picks out one byte of memory or one register. Addresses in this guide
    are written in hex.

Argument
:   A word typed after a program's name to tell it what to work on.

Baud
:   Bits a second on a serial line.

BIOS
:   Basic Input/Output System. The program in the ROM chips that starts the Griffin Jr.,
    runs the monitor and does the routine work for other programs.

Bit
:   A single on-or-off value. Eight make a byte.

Bus error
:   What the processor reports when it asks for an address and nothing answers.

Byte
:   Eight bits, enough for a number from 0 to 255. One character of text or one dot of the
    picture.

CPLD
:   A chip of simple logic whose arrangement is loaded into it. The Griffin Jr. has two,
    which tie all the other chips together.

Cursor
:   The white block that shows where the next character you type will go.

Directory
:   A named group of files on a drive. Also called a folder.

Drive
:   A place where files are kept. C: is in the ROM chips and D: is the SD card.

File
:   A named piece of stored information.

Flash memory
:   Memory that keeps its contents without power and can be rewritten in blocks. The ROM
    chips are flash memory.

Hex
:   Hexadecimal: counting in sixteens, with the digits 0 to 9 and a to f.

Interrupt
:   A signal that makes the processor set aside what it is doing to deal with something
    that cannot wait.

KB
:   Kilobyte: 1,024 bytes.

Monitor
:   The part of the BIOS that prints the prompt and carries out the commands you type.

NTSC
:   The colour television system used in North America and Japan.

Page
:   One complete picture in memory. The Griffin Jr. has two and shows one at a time.

Program
:   A list of instructions for the computer.

Prompt
:   The `C:/>` that shows the monitor is ready for a command.

RAM
:   Random access memory. The working memory, which forgets everything when the power
    goes off.

Register
:   An address that is connected to a part of the machine instead of to memory. Also one
    of the processor's own places for holding a number.

ROM
:   Read-only memory. Memory that keeps its contents without power.

Sample
:   One number in the list of numbers that makes up a recorded sound.

Script
:   A text file of monitor commands, with a name ending in `.CMD`.

SDK
:   Software development kit. The files a programmer needs to write programs for the
    Griffin Jr. in C.

System call
:   A request from a program to the BIOS.

Variable
:   In BASIC, a name that stands for a number or a piece of text.

Word
:   Two bytes taken together: 16 bits.
