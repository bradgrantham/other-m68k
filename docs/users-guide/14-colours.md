# The colour chart

Each square shows one colour with its byte in hex. The first digit of the byte is the row
and the second is the column. Chapter 7 explains how the number is made up.

![All 256 colours.](figures/colours.svg){width=100%}

Printed colours and television colours never match exactly, and one television differs
from another, so treat the chart as a guide and trust your own screen.

Some useful colours:

| Colour | Hex | Decimal | In BASIC |
|--------|----|----|--------------|
| Black | `00` | 0 | `RGB(0, 0, 0)` |
| White | `ff` | 255 | `RGB(255, 255, 255)` |
| Red | `e0` | 224 | `RGB(255, 0, 0)` |
| Green | `1c` | 28 | `RGB(0, 255, 0)` |
| Blue | `03` | 3 | `RGB(0, 0, 255)` |
| Yellow | `fc` | 252 | `RGB(255, 255, 0)` |
| Cyan | `1f` | 31 | `RGB(0, 255, 255)` |
| Magenta | `e3` | 227 | `RGB(255, 0, 255)` |
| Orange | `f0` | 240 | `RGB(255, 145, 0)` |
| Mid grey | `92` | 146 | `RGB(145, 145, 170)` |
| The screen's dark blue | `01` | 1 | `RGB(0, 0, 85)` |
