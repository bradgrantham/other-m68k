Extras for the Griffin Jr. SD card (drive D:)

Copy these files to a FAT32 microSD card. Put the
card in before you connect the power.

Programs: type the name at the prompt.

  SSTV.ELF     sends a picture as slow-scan TV sound
               sstv            the screen
               sstv PIC.BMP    a picture file
  FSTEST.ELF   checks that files can be written
               and read back
  LS.ELF       programmers' examples. The monitor
  CAT.ELF      has ls and cat of its own, so type
               ls.elf or cat.elf to run these

BASIC programs from chapter 5 of the User's Guide:
type  basic D:NAME.BAS

  GUESS.BAS    guess the number
  SCENE.BAS    a picture made of shapes
  BALL.BAS     a bouncing ball
  SONG.BAS     a round for two voices
  SKETCH.BAS   draw with the joystick
  CATCH.BAS    catch the falling stars

GREET.CMD is the script from chapter 3: type  greet

To keep a program on drive C: so that it works
without the card:  copy D:SSTV.ELF C:
